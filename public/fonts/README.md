# CIVIS Inter font assets

These files are byte-for-byte copies of the Inter 4.001 variable WOFF2 subsets
previously downloaded by this project's `next/font/google` configuration. The
embedded font version is `Version 4.001;git-66647c0bb`; the weight axis remains
100–900. No font outlines, names, glyphs, weights or metrics were modified.

The existing Latin preload is handled by `next/font/local`; the other six
subsets retain their original Unicode ranges in `app/inter-subsets.css`. The
previous Inter fallback metrics are also preserved.
